# RazorPM

Простая система управления проектами и задачами на ASP.NET Core Razor Pages с локальной базой данных SQLite. 

Позволяет вести проекты команды, назначать задачи, контролировать сроки и фактические трудозатраты, а также формировать сводные PDF-отчёты.

## Возможности

- **Проекты и участники:** создание проектов, назначение команды, статусы («В работе», «Завершён») и архивация завершённых проектов.
- **Трекинг задач:** установка приоритетов, дедлайнов и фиксация затраченного времени (`SpentHours`). Фильтры по статусам, исполнителям и проектам.
- **Работа над задачей:** карточка с историей изменений (аудит-лог), веткой комментариев и прикреплением файлов.
- **Календарь и Гант:** просмотр дедлайнов в виде ежемесячной сетки и наглядный таймлайн задач проекта.
- **PDF-отчёты:** выгрузка сводки по проектам и часам через QuestPDF.
- **Две роли:**
  - `admin` — доступ к админке, управление учётными записями (смена ролей, отключение) и просмотр всех проектов;
  - `user` — работа со своими задачами и проектами, где пользователь назначен участником.
- **Безопасность и кастомизация:** сессионная авторизация, хэширование паролей через `PasswordHasher<User>`, валидация сложности, восстановление пароля по почте, тёмная и светлая темы интерфейса.

## Стек технологий

- **Backend:** C# 12, .NET 8, ASP.NET Core Razor Pages
- **База данных:** SQLite + Entity Framework Core 8 (Code First, автомиграции)
- **Отчёты:** QuestPDF
- **Frontend:** чистый HTML5/CSS3 (с CSS-переменными для тем), немного JavaScript

## Запуск проекта

Для запуска достаточно установленного [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/eueeeo/Razor-PM.git
   cd Razor-PM
   ```

2. Запустите приложение:
   ```bash
   dotnet run --project razorpm
   ```

При первом старте EF Core автоматически создаст локальную базу `pmrazor.db` и наполнит её начальными демо-данными. Приложение откроется на `http://localhost:5162` (или порту из вывода терминала).

> По умолчанию настройки почты в `appsettings.json` содержат заглушки. Если хотите проверять отправку писем при сбросе пароля, укажите параметры своего SMTP-сервера в блоке `EmailSettings`.

## Демо-доступ

Для быстрого ознакомления в системе уже созданы две учётные записи:

- **Администратор:** `admin` / `Admin#4826Work` (полный доступ, панель `/AdminDashboard`)
- **Пользователь:** `demo` / `Demo#7319Task` (работа с задачами и проектами)

Также доступна свободная регистрация нового пользователя на странице `/Register`.
