# RazorPM

Веб-приложение для управления проектами и задачами небольшой команды. Позволяет вести проекты, распределять задачи между исполнителями, контролировать сроки и фактические трудозатраты, смотреть расписание в календаре и на диаграмме Ганта, а также формировать сводные PDF-отчёты.

Стек: **ASP.NET Core 8 (Razor Pages)**, **Entity Framework Core** и **SQLite**.

---

## Основные возможности

### Проекты и задачи
- Создание и редактирование проектов, архивация и назначение участников команды.
- Задачи со статусами («В работе», «Завершено»), приоритетами (низкий, средний, высокий) и дедлайнами.
- Учёт фактически затраченного времени на каждую задачу (`SpentHours`).
- Карточка задачи с историей изменений (аудит-лог), комментариями и прикреплением файлов.
- Поиск и фильтрация по статусам, приоритетам, проектам и исполнителям.

### Визуализация и отчёты
- **Календарь:** сетка месяца с наглядным отображением сроков и дедлайнов задач.
- **Диаграмма Ганта:** интерактивный таймлайн распределения задач проекта по времени.
- **PDF-отчёты:** сводная статистика по проектам, задачам и трудозатратам с экспортом в PDF через QuestPDF.

### Безопасность и доступ
- Две роли:
  - `admin` — доступ к админ-панели (`/AdminDashboard`), управление пользователями (смена ролей, блокировка) и просмотр всех проектов;
  - `user` — работа со своими проектами и задачами, где пользователь назначен исполнителем или участником команды.
- Авторизация на сессиях (cookie-based).
- Хэширование паролей через `PasswordHasher<User>` (PBKDF2) — пароли не хранятся в открытом виде.
- Проверка сложности пароля при регистрации и смене, а также сброс пароля по ссылке с токеном на почту.
- Тёмная и светлая темы оформления (выбор сохраняется в профиле пользователя).

## Стек технологий

- **Платформа:** .NET 8 (C# 12)
- **Фреймворк:** ASP.NET Core 8 Razor Pages
- **База данных:** SQLite + Entity Framework Core 8 (Code First, автомиграции)
- **Генерация PDF:** QuestPDF
- **Фронтенд:** чистый HTML5, CSS3 (CSS-переменные для переключения тем), JavaScript

## Как запустить

Для запуска проекта потребуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/eueeeo/Razor-PM.git
   cd Razor-PM
   ```

2. Запустите приложение:
   ```bash
   dotnet run --project razorpm
   ```

При первом запуске Entity Framework Core автоматически создаст локальную базу данных `pmrazor.db`, применит миграции и добавит начальные демо-данные (учётные записи, тестовые проекты и задачи).

Приложение откроется в браузере по адресу `http://localhost:5162` (или по адресу, указанному в консоли).

> **Почта:** по умолчанию в `appsettings.json` для параметров SMTP указаны тестовые заглушки. Если хотите проверять отправку писем при сбросе пароля, укажите данные своего почтового сервера в блоке `EmailSettings`.

## Тестовые учётные записи

В базе данных уже настроены два аккаунта для быстрой проверки функционала:

| Логин | Пароль | Роль | Возможности |
|---|---|---|---|
| `admin` | `Admin#4826Work` | Администратор | Полный доступ, админ-панель, управление ролями и блокировка пользователей |
| `demo` | `Demo#7319Task` | Пользователь | Создание своих проектов, работа с назначенными задачами, календарь, Гант |

Также доступна свободная регистрация нового пользователя на странице `/Register`.
