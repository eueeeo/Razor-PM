# RazorPM

Веб-приложение для управления проектами и задачами небольшой команды. Позволяет вести проекты, распределять задачи между исполнителями, контролировать сроки и фактические трудозатраты, смотреть расписание в календаре и на диаграмме Ганта, а также формировать сводные PDF-отчеты.

## Основные возможности

### Проекты и задачи
- Создание и редактирование проектов, архивация и назначение участников команды
- Задачи со статусами («В работе», «Завершено»), приоритетами (низкий, средний, высокий) и дедлайнами
- Учет фактически затраченного времени на каждую задачу (`SpentHours`)
- Карточка задачи с историей изменений (аудит-лог), комментариями и прикреплением файлов
- Поиск и фильтрация по статусам, приоритетам, проектам и исполнителям

### Визуализация и отчеты
- **Календарь:** сетка месяца с отображением сроков и дедлайнов задач
- **Диаграмма Ганта:** интерактивный таймлайн распределения задач проекта по времени
- **PDF-отчеты:** сводная статистика по проектам, задачам и трудозатратам с экспортом в PDF через QuestPDF

### Безопасность и доступ
- Две роли доступа:
  - `admin` — доступ к админ-панели (`/AdminDashboard`), управление пользователями (смена ролей, блокировка) и просмотр всех проектов
  - `user` — работа со своими проектами и назначенными задачами
- Аутентификация на основе cookie-сессий
- Хэширование паролей через `PasswordHasher<User>` (PBKDF2)
- Проверка сложности пароля и возможность сброса по токену
- Переключение тёмной и светлой тем оформления

## Стек технологий

- **Платформа:** .NET 8 (C# 12)
- **Фреймворк:** ASP.NET Core 8 Razor Pages
- **База данных и ORM:** SQLite, Entity Framework Core 8 (Code First, автомиграции)
- **Генерация отчетов:** QuestPDF
- **Фронтенд:** HTML5, CSS3 (CSS-переменные для тем), JavaScript

## Структура проекта

- `razorpm/Data/` — контекст базы данных (`AppDbContext`)
- `razorpm/Migrations/` — миграции Entity Framework Core
- `razorpm/Models/` — доменные модели (`User`, `Project`, `TaskItem`, `TaskComment` и др.)
- `razorpm/Pages/` — страницы Razor Pages и обработчики (`AdminDashboard`, `Calendar`, `Gantt`, `Reports`, `Tasks`)
- `razorpm/Services/` — сервисы приложения (`EmailService`)
- `razorpm/wwwroot/` — статические файлы (стили, скрипты, вложения)
- `razorpm/appsettings.json` — конфигурация подключения к SQLite и параметры приложения
- `razorpm/Program.cs` — настройка DI, middleware, миграции и сидирование данных

## Установка и запуск

Для работы требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/eueeeo/Razor-PM.git
   cd Razor-PM
   ```

2. **Запустить проект:**
   ```bash
   dotnet run --project razorpm
   ```
   При первом запуске база данных SQLite (`pmrazor.db`), миграции и начальные данные создаются автоматически.

Приложение откроется по адресу `http://localhost:5162`.

## Тестовые учетные записи

В базе данных уже настроены два аккаунта для быстрой проверки функционала:

| Логин | Пароль | Роль | Доступ |
|---|---|---|---|
| `admin` | `Admin#4826Work` | Администратор | Полный доступ, админ-панель, управление ролями и блокировка пользователей |
| `demo` | `Demo#7319Task` | Пользователь | Создание проектов, работа с назначенными задачами, календарь, Гант |

Также доступна свободная регистрация нового пользователя на странице `/Register`.
