# RazorPM — Веб-приложение для управления проектами и задачами

Учебный проект веб-приложения на стеке **ASP.NET Core 8 (Razor Pages)** и **Entity Framework Core**, разработанный для практики создания классических веб-приложений: реализации CRUD-операций, связей между сущностями, ролевой модели доступа, безопасной аутентификации и формирования отчётов.

Приложение позволяет организовывать работу над проектами: создавать задачи, назначать исполнителей, фиксировать затраченное время, прикреплять файлы, оставлять комментарии, отслеживать сроки на интерактивном календаре и диаграмме Ганта, а также выгружать сводные отчёты в формате PDF.

---

## Основные возможности

- **Управление проектами:**
  - Создание, редактирование и просмотр проектов со статусами (`active`, `done`).
  - Архивирование и разархивирование проектов.
  - Назначение участников команды на проекты.
  - Фильтрация и поиск проектов по названию и статусу.

- **Управление задачами:**
  - Создание и редактирование задач с привязкой к проекту и исполнителю.
  - Указание дат начала (`StartDate`) и дедлайна (`DueDate`).
  - Приоритеты задач (`low`, `medium`, `high`) и статусы выполнения (`active`, `done`).
  - Учёт фактически затраченного времени на задачу в часах (`SpentHours`).
  - Фильтрация задач по проектам, исполнителям, статусам и приоритетам.

- **История и взаимодействие по задачам:**
  - Комментирование задач с фиксацией автора и времени публикации.
  - Журнал аудита (`TaskHistory`): автоматическая запись изменений статусов и действий по задаче.
  - Прикрепление файлов (вложений) к задачам с сохранением в локальное хранилище.

- **Визуализация сроков:**
  - **Календарь:** ежемесячный интерактивный календарь с отображением запланированных задач по датам.
  - **Диаграмма Ганта:** наглядный таймлайн распределения задач проекта по времени.

- **Отчёты и экспорт в PDF:**
  - Страница аналитики со сводными таблицами проектов и задач.
  - Экспорт сформированного отчёта в документ PDF с помощью библиотеки QuestPDF.

- **Аутентификация и безопасность:**
  - Сессионная аутентификация на основе cookie (`Cookie-based session`).
  - Хэширование паролей с использованием стандартного `IPasswordHasher<User>` из ASP.NET Core Identity (алгоритм PBKDF2 с HMAC-SHA256). Пароли в базе данных не хранятся в открытом виде.
  - Серверная валидация сложности паролей при регистрации, смене и сбросе пароля (минимум 8 символов, заглавная и строчная буквы, цифра и спецсимвол).
  - Смена пароля авторизованным пользователем.
  - Восстановление доступа через токен сброса пароля с ограниченным сроком действия (1 час).
  - Автоматическая безопасная миграция устаревших открытых паролей в хэши при первом успешном входе.

- **Интерфейс:**
  - Поддержка светлой и тёмной темы оформления (выбор сохраняется в профиле пользователя в БД).
  - Адаптивная верстка на чистом CSS с использованием CSS-переменных.

## Используемые технологии и инструменты

- **Платформа:** .NET 8 (C# 12)
- **Фреймворк:** ASP.NET Core 8 Razor Pages
- **ORM:** Entity Framework Core 8.0 (Code-First)
- **База данных:** SQLite (`Microsoft.EntityFrameworkCore.Sqlite`)
- **Миграции БД:** EF Core Migrations (`Microsoft.EntityFrameworkCore.Design`, `Microsoft.EntityFrameworkCore.Tools`)
- **Безопасность:** `Microsoft.AspNetCore.Identity.PasswordHasher<User>`, ASP.NET Core Session
- **Генерация PDF:** QuestPDF (Community License)
- **Работа с почтой:** `System.Net.Mail` (SMTP)
- **Фронтенд:** HTML5, CSS3, чистый JavaScript (без сторонних UI-фреймворков)
- **Среда разработки:** Visual Studio / VS Code / Rider

## Роли пользователей

В приложении реализовано разделение прав доступа на основе ролей:

| Роль | Возможности в системе |
|---|---|
| **Администратор (`admin`)** | - Доступ к панели администратора (`/AdminDashboard`).<br>- Управление пользователями (`/Users`): просмотр списка, назначение ролей (`user` / `admin`), блокировка и разблокировка учётных записей.<br>- Полный доступ ко всем проектам и задачам системы.<br>- Формирование отчётов и выгрузка аналитики в PDF. |
| **Пользователь (`user`)** | - Создание собственных проектов (становится их владельцем) и задач.<br>- Доступ к проектам, в которые он добавлен участником команды.<br>- Выполнение задач, отметка затраченных часов, добавление комментариев и файлов.<br>- Просмотр личного календаря и диаграммы Ганта.<br>- Управление личным профилем, смена пароля и темы оформления. |

## Демонстрационные учётные записи

Для удобства проверки функционала при первом запуске в базе данных автоматически создаются две учётные записи:

| Логин | Пароль | Роль | Описание |
|---|---|---|---|
| `admin` | `Admin#4826Work` | `admin` | Полный доступ, включая админ-панель и управление ролями пользователей |
| `demo` | `Demo#7319Task` | `user` | Стандартная учётная запись пользователя с тестовыми проектами и задачами |

> Пароли демо-пользователей при первом запуске автоматически хэшируются и сохраняются в БД исключительно в виде хэшей.

## Пошаговая инструкция по запуску (Windows)

### Предварительные требования
- Установленный [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (версия 8.0 или выше).
  Проверить установку можно командой в командной строке:
  ```cmd
  dotnet --version
  ```

### Запуск проекта

1. **Клонируйте репозиторий или скачайте архив с кодом:**
   ```cmd
   git clone <URL_РЕПОЗИТОРИЯ>
   cd RazorPM
   ```

2. **Перейдите в каталог проекта:**
   ```cmd
   cd razorpm
   ```

3. **Запустите проект:**
   ```cmd
   dotnet run
   ```

4. **Откройте приложение в браузере:**
   После запуска в консоли отобразится локальный адрес. Перейдите по нему в браузере:
   - `http://localhost:5162` или `https://localhost:7127`

5. **Вход в систему:**
   На странице входа используйте учётные данные администратора (`admin` / `Admin#4826Work`) или тестового пользователя (`demo` / `Demo#7319Task`), либо зарегистрируйте новый аккаунт на странице `/Register`.

## Инициализация базы данных

При первом запуске приложения **не требуется вручную выполнять SQL-скрипты**:
1. При старте `Program.cs` вызывает метод `db.Database.Migrate()`, который автоматически применяет миграцию Entity Framework Core (`InitialCreate`) и создаёт локальный файл базы данных SQLite `pmrazor.db` с необходимой структурой таблиц, внешними ключами и индексами.
2. Метод инициализации `SeedDemoData` наполняет базу начальными демонстрационными данными:
   - Создаются пользователи `admin` и `demo` с хэшированными паролями.
   - Создаются 3 демонстрационных проекта с разными статусами.
   - Пользователь `demo` привязывается к проекту в качестве участника команды.
   - Создаются 3 демонстрационные задачи с назначенными исполнителями, приоритетами и часами.
3. При последующих запусках сидинг проверяет наличие существующих записей и повторно данные не дублирует.

## Примечание

Проект носит учебный характер и создан для демонстрации архитектуры веб-приложений на ASP.NET Core и Entity Framework Core. 

В конфигурации `appsettings.json` параметры почтового сервера (`EmailSettings`) по умолчанию содержат безопасные шаблоны-заглушки. Для полноценной отправки писем при регистрации и восстановлении пароля необходимо указать действующие параметры вашего SMTP-сервера. Если почта не настроена, приложение обрабатывает это безопасно: регистрация и создание токенов восстановления завершаются без падения программы.
