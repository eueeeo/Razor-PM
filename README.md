# RazorPM

Веб-приложение для управления проектами и задачами: создание проектов, распределение задач по исполнителям, учёт затраченного времени, интерактивный календарь, диаграмма Ганта и выгрузка отчётов в PDF. Написано на ASP.NET Core 8 (Razor Pages), Entity Framework Core и SQLite.

## Основные возможности

**Проекты и задачи**
- создание и редактирование проектов со статусами («В работе», «Завершён») и архивацией
- назначение участников команды на проекты
- задачи с приоритетами (низкий, средний, высокий), статусами и дедлайнами
- учёт фактически затраченного времени по каждой задаче (в часах)
- фильтрация и поиск по проектам, исполнителям, статусам и приоритетам

**Детали задач и совместная работа**
- комментарии к задачам с указанием автора и даты
- журнал истории изменений по каждой задаче
- прикрепление файлов к задачам

**Календарь и диаграмма Ганта**
- сетка месяца с отображением дедлайнов задач
- диаграмма Ганта (таймлайн) для наглядного контроля сроков по проектам

**Отчёты**
- сводная статистика по проектам, задачам и часам
- экспорт сформированного отчёта в PDF через QuestPDF

**Безопасность и профиль**
- авторизация на cookie-сессиях
- безопасное хэширование паролей через `PasswordHasher<User>` (PBKDF2)
- проверка сложности пароля при регистрации, смене и сбросе (от 8 символов, заглавная, строчная, цифра, спецсимвол)
- сброс пароля по ссылке с токеном на почту
- переключение светлой и тёмной темы (сохраняется в профиле)

**Роли**
- `admin` — видит все проекты, управляет пользователями в админ-панели (роли, блокировка)
- `user` — свои проекты и проекты, где назначен участником, работа с задачами

## Технологии
- .NET 8, C# 12
- ASP.NET Core 8 Razor Pages
- Entity Framework Core 8, SQLite
- QuestPDF (генерация PDF)
- HTML, CSS, JavaScript (без сторонних UI-фреймворков)

## Структура проекта
```
Data/             контекст базы данных (AppDbContext)
Migrations/       миграции EF Core
Models/           модели данных (User, Project, TaskItem, TaskComment и др.)
Pages/            Razor Pages
  Index           главная панель со сводкой задач и проектов
  Projects        список, создание и редактирование проектов
  Tasks           список, фильтры и карточки задач
  TaskDetails     детали задачи, комментарии, вложения и история
  Calendar        календарь с дедлайнами задач
  Gantt           диаграмма Ганта
  Reports         отчёты и экспорт в PDF
  AdminDashboard  панель администратора
  Users           управление пользователями (роли, активность)
  Profile         профиль пользователя
  Login/Register  вход, регистрация, смена и восстановление пароля
Services/         отправка писем (EmailService)
wwwroot/          стили (site.css), иконки, клиентские библиотеки и uploads
Program.cs        настройка DI, конвейера и автоматический сидинг
appsettings.json  строка подключения и настройки SMTP
```

## Как запустить
Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

В `appsettings.json` по умолчанию настроена локальная база SQLite:
```json
"ConnectionStrings": {
  "DefaultConnection": "Data Source=pmrazor.db"
}
```
Если нужно тестировать отправку писем при регистрации или сбросе пароля, укажите свои параметры SMTP в блоке `EmailSettings`.

Запуск из папки репозитория:
```bash
dotnet run --project razorpm
```
(или перейти в папку `razorpm` и выполнить `dotnet run`).

При первом запуске автоматически создаётся база `pmrazor.db` через миграции EF Core и наполняется демонстрационными данными. Адрес приложения появится в консоли (по умолчанию `http://localhost:5162`).
